# Helix Fuel — Protótipos de UX

Protótipos navegáveis do Helix Fuel (ERP para redes de postos de combustíveis).

**Abra o demo:** [index.html](./index.html) — reúne os 11 módulos numa navegação única.

Módulos individuais em [`/modulos`](./modulos):
Central da rede · Relatórios · Cadastros · Estoque & tanques · Fiscal NFC-e · Financeiro · Configurações · Fechamento de turno · Frente de caixa (PDV) · Pista (frentista) · Portal do cliente.

> Protótipos de demonstração: dados fictícios, integrações simuladas, nada é persistido.
